# PDF téléchargeable — Fiche B « Faire-part instantané »

Contenu **d'une page A4** à mettre en forme avec Google Docs, Word ou Pages,
puis exporter en PDF et déposer sur l'annonce Etsy comme fichier téléchargeable.

Le style visuel doit rester **sobre et de la même famille que le site** :
couleurs crème/vert botanique, typographie Cormorant Garamond pour le titre,
Jost pour le texte courant (les mêmes que le thème `botanique` du produit).

Le PDF est le **même pour tous les acheteurs**. C'est le tunnel qui reçoit
le numéro de commande Etsy comme identifiant unique (à défaut d'un vrai code
injecté par acheteur, ce qui n'est pas possible avec Etsy Instant Download).

## Notes pour la mise en forme

- **Titre en haut** : « UN OUI, UNE HISTOIRE » en Cormorant Garamond, corps
  ~28pt, avec un filet horizontal sous le nom.
- **Corps du texte** : Jost 12pt, interligne 1,4.
- **Titres d'étape** (« ÉTAPE 1 » etc.) : Jost 11pt, majuscules,
  interlettrage élargi (~0.14em), couleur `#446042` (vert sage sombre).
- **Le nom du site `unouiunehistoire.fr/commande`** : dans un cadre discret
  vert clair, corps 14pt.
- **Marges** : 2 cm tout autour.
- **Fond** : ivoire `#f7f3ec` si l'export PDF le permet, blanc sinon.
- **Aucun QR code** — l'acheteur est déjà en train de lire sur écran, il
  clique le lien plutôt que de le scanner.

## Après export PDF

- **Taille finale** : < 500 Ko (compresser si Word donne un fichier plus lourd).
- **Nom de fichier** : `un-oui-une-histoire-faire-part-instantane.pdf`.
- **À déposer sur Etsy** : « Files » de l'annonce Fiche B, cocher
  « Instant Download ».
- **À tester avant publication** : acheter à toi-même via un deuxième compte
  Etsy, vérifier que le PDF est bien livré, que le tunnel accepte le numéro
  de commande, et que le site généré est propre.
